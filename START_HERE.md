## 🔍 SEO Terminology Simplified

| Term | Meaning |
|------|---------|
| **robots.txt** | File that tells Google which pages to crawl |
| **sitemap.xml** | File listing all your important pages |
| **Schema markup** | Code that tells Google what your page is about |
| **Title tag** | The main headline for a page in search results |
| **Meta description** | The short description under the title in search |
| **Canonical tag** | Tells Google which version of a page is the original |
| **Organic traffic** | Visitors from search engines (not ads) |
| **CTR** | Click-Through Rate - % of people who click your link |
| **Core Web Vitals** | Google's performance metrics (speed, stability) |
